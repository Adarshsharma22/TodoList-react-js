# 🚀 Task Manager Web App

A modern, feature-rich **Task Manager Application** built using **React.js** to help users efficiently organize, track, and manage their daily activities.

Designed with a focus on **clean UI, smooth UX, and real-world functionality**, this project demonstrates practical frontend development skills and problem-solving ability.

---

## 🌟 Overview

Managing daily tasks can become overwhelming without proper tools. This application provides a simple yet powerful interface for users to:

- Plan their day  
- Track completed work  
- Stay organized  
- Improve productivity  

The app ensures that tasks remain saved even after page refresh using **LocalStorage**, making it reliable for everyday use.

---

## ✨ Key Features

### 📝 Task Management
- Add new tasks easily  
- Edit existing tasks  
- Delete unwanted tasks  
- Mark tasks as completed  

### 💾 Data Persistence
- Stores tasks in **LocalStorage**  
- Data remains intact even after refresh  
- No backend required  

### 🎨 UI/UX Design
- Modern glassmorphism-inspired design  
- Smooth animations and transitions  
- Hidden scrollbar for clean look  
- Fully responsive layout  

### ⚡ Performance
- Optimized React rendering  
- Efficient state updates  
- Lightweight and fast

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

``bash
### 1. Clone the repository
git clone https://github.com/Adarshsharma22/TodoList-react-js.git

### 2. Navigate to project directory
cd TodoList-react-js

### 3. Install dependencies
npm install

### 4. Start development server
npm run dev

## 💡 Challenges Faced & Solutions
